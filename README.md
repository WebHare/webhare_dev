# webhare_dev

This is the webhare_dev project, a collection of code code snippets and AI instructions shared between WebHare developers.

All code here should be MIT licensed or public domain. Do not contribute code or data that can not be shared as such.

Do not contribute code identifying customers, users or other persons who did not give permission for their data to be used.

Nothing in this repository should be considered 'official' or 'supported', not even if written by WebHare developers. Examples
may be outdated or rely on unstable internal APIs. Any interface not covered by WebHare's CI test is especially subject to change.

Keep code and documentation in English. Feel free to change and add code and AI instructions where useful/warranted, but any attempt
to submit malicious or dangerous code will result in loss of access to the project. Don't conduct security experiments or similar
things without discussing it first, this repository doesn't work if the members cannot trust each other or the code. Having said that,
all code here is without warranty. Use at your own risk.

Code and documentation that is mature enough should be submitted for inclusion in the WebHare platform (eg as part of the vscode extension)
or for eg. the https://www.webhare.dev/ site.

If you intend to make large scale changes, refactors or additions, please discuss them first.

Discussion and questions about code are welcome on https://github.com/WebHare/webhare_dev. Please do not use the issue tracker
to ask others to write code for you, or to ask for help with your own code. It's strictly meant to discuss the content in the repository.

If the issue you want to discuss is sensitive or may be a security issue that shouldn't tbe discussed in public, contact security@webhare.nl instead.
